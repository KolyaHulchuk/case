# Рев'ю доступів «ПейТест» (кейс 1)

Скрипт `case.py` проводить квартальне рев'ю доступів: порівнює фактичні акаунти
(`accounts.csv`) з даними HR (`employees.csv`) і ролевою моделлю та знаходить
невідповідності.

## Що перевіряється

- акаунт не прив'язаний до працівника з HR;
- акаунт звільненого працівника або працівника у відпустці досі існує;
- в акаунт входили після дати звільнення чи початку відпустки;
- роль не відповідає посаді за ролевою моделлю;
- правило 1: SoD, тобто `operator` + `refund_approver` у BO в однієї людини;
- правило 2: постійний `admin` у BO;
- правило 3: акаунтом не користувалися понад 90 днів;
- правило 4: немає корпоративної пошти `@paytest.ua`.

## Дані та припущення

- `employees.csv` і `accounts.csv` скопійовані з PDF тестового завдання.
- Ролева модель і правила записані в коді константами: `ROLE_MODEL`,
  `INACTIVITY_LIMIT_DAYS` (90 днів), `CORPORATE_DOMAIN` (`@paytest.ua`).
- Дата рев'ю в завданні не вказана, тому вона задана константою `REVIEW_DATE`
  (2026-11-13, наступний день після найновішого `last_login`).

## Вміст папки

```
case/
├── case.py                          скрипт
├── employees.csv                    вивантаження з HR
├── accounts.csv                     вивантаження акаунтів
├── findings.csv                     результат роботи скрипта (створюється автоматично)
├── access_review_table_final.xlsx   фінальна таблиця з ризиком, дією і пріоритетом
└── README.md
```

Для запуску потрібні лише `case.py`, `employees.csv` і `accounts.csv` в одній папці.

## Як запустити

Потрібен Python 3.7 або новіший. Сторонні бібліотеки не потрібні, тільки стандартна
(`csv`, `datetime`, `collections`, `pathlib`).

З папки скрипта:

```bash
cd case
python3 case.py
```

або з будь-якої іншої папки, вказавши шлях до скрипта:

```bash
python3 шлях/до/case/case.py
```

Скрипт шукає CSV-файли поруч із собою, а не в папці, з якої його запустили:
шляхи будуються від `Path(__file__).resolve().parent`.

## Результат

- У терміналі виводиться таблиця знахідок, їх загальна кількість і повний шлях до файлу результату.
- Знахідки зберігаються у `findings.csv` поруч зі скриптом, з колонками `system`, `login`,
  `problem`. Якщо файл уже є, він перезаписується.

Скрипт фіксує лише факти. Ризик, рекомендовану дію і пріоритет визначає аналітик,
вони внесені у `access_review_table_final.xlsx`.
